Engineering Architecture Reference

Rxify — Software Requirements Specification (SRS)

Object-Oriented Domain-Driven Architecture & Implementation Blueprint

1. System Vision & Architectural Principles

Single Responsibility Eliminate monolithic files (>1000 lines). Every file has a single role: Repository, Service, or Entity.
Service-Repository Pattern Repositories encapsulate SQL data access. Services manage business rules. Routers remain thin controllers.
Modular Frontend Components kept strictly under 150 lines. React Query for server cache, Zustand for local UI toggles.
